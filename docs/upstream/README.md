# Upstream README archive

Tacit began as a fork of [TermCanvas](https://github.com/blueberrycongee/termcanvas)
by blueberrycongee. These are that project's README files as they stood at the
point Tacit's own README was written, kept verbatim.

They are here for attribution and history. They describe TermCanvas, not Tacit,
and are not maintained.
